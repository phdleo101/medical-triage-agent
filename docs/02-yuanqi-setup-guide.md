# 腾讯元器搭建指南 — 智能分诊Agent

> 本指南指导你从零在腾讯元器平台搭建智能分诊Bot，包括注册账号、创建智能体、导入知识库、配置提示词、发布上线。
> 预计耗时：30-60分钟
> 平台地址：https://yuanqi.tencent.com

---

## 前置准备

### 需要的文件

项目目录 `data/knowledge/` 下有3个知识库文件（Markdown格式，腾讯元器原生支持）：
1. `symptom_department_mapping.md` — 症状→科室映射库（90个症状，8大身体部位）
2. `emergency_symptoms.md` — 紧急症状识别库（红/黄/绿三级）
3. `disease_encyclopedia.md` — 常见疾病科普库（50种疾病）

### 平台简介

**腾讯元器**是腾讯推出的一站式AI智能体创建与分发平台，支持：
- 零代码可视化搭建智能体
- 知识库RAG（支持PDF/DOC/MD/TXT等多种格式）
- 工作流编排
- 多渠道发布（网页/公众号/微信等）
- 底层使用腾讯混元大模型

---

## 第一步：注册/登录腾讯元器

1. 打开 https://yuanqi.tencent.com
2. 点击右上角「登录」
3. 支持以下方式登录：
   - 微信扫码登录（推荐，最快捷）
   - 手机号登录
4. 登录后进入元器工作台首页

---

## 第二步：创建智能体

1. 在首页点击「新建智能体」
2. 选择 **「对话式智能体」**（不是公众号智能体）
   - 对话式智能体：支持知识库+工作流，可发布到网页等渠道 ← **选这个**
   - 公众号智能体：专门用于公众号文章导入和回复
3. 填写基本信息：
   - **名称**：智能分诊助手
   - **简介**：基于症状的智能分诊推荐系统，帮助患者找到正确的就诊科室，评估紧急程度
4. 点击「创建」

---

## 第三步：配置智能体提示词

在智能体编辑页面，找到「角色设定」或「提示词」区域，粘贴以下内容：

```
# 角色
你是一名专业的智能分诊助手，帮助患者根据症状找到正确的就诊科室。

# 核心职责
1. 症状采集：通过多轮对话，耐心收集患者的症状信息
2. 紧急评估：根据症状判断紧急程度（红色=立即急诊/黄色=24h内就诊/绿色=常规就诊）
3. 科室推荐：根据症状推荐最合适的就诊科室
4. 就诊建议：提供就诊前准备建议和健康科普
5. 免责提醒：每次回复都包含免责声明

# 工作流程
1. 先询问患者哪里不舒服
2. 根据患者描述，追问关键信息（症状部位/持续时间/严重程度/伴随症状）
3. 查询知识库，匹配症状→科室映射
4. 评估紧急程度
5. 给出分诊建议

# 回复格式
每次分诊建议包含以下内容：
- 【紧急程度】：红色/黄色/绿色 + 说明
- 【推荐科室】：科室名称
- 【可能原因】：简要列举（不超过3个）
- 【就诊建议】：具体建议
- 【免责声明】：本建议仅供参考，不构成医疗诊断，紧急情况请拨打120

# 严格规则
- 不做诊断，只做分诊推荐
- 不推荐具体药物
- 不回答"我得了什么病"
- 遇到紧急症状（红色），优先建议立即急诊或拨打120
- 对儿童（<14岁）、孕妇、老年人（>65岁）特殊关注
- 如果患者描述模糊，主动追问关键信息
- 每次回复都必须包含免责声明

# 对话风格
- 温和专业、耐心细致
- 使用通俗语言，避免过多医学术语
- 关键信息加粗显示
- 回答简洁，不超过300字
```

> 💡 腾讯元器提供「AI优化提示词」功能，可以点击优化按钮让AI帮你润色提示词。

## 第四步：创建知识库

### 4.1 进入知识库管理

1. 在智能体编辑页面左侧导航栏，点击「知识库」
2. 点击「创建知识库」
3. 选择 **「通用知识库」**（不是公众号知识库）

### 4.2 创建第一个知识库

1. 知识库名称：`症状科室映射库`
2. 知识库描述：`90个常见症状到就诊科室的映射关系，按8大身体部位分类`
3. 点击「创建」
4. 点击「导入文档」→「本地上传」
5. 选择文件：`symptom_department_mapping.md`
6. 等待处理完成（状态显示「已处理」）

### 4.3 创建第二个知识库

重复上述步骤：
- 知识库名称：`紧急症状识别库`
- 知识库描述：`红/黄/绿三级紧急症状识别标准与危急值预警`
- 上传文件：`emergency_symptoms.md`

### 4.4 创建第三个知识库

重复上述步骤：
- 知识库名称：`疾病科普库`
- 知识库描述：`50种常见疾病的科普信息，包含症状、就诊科室、保健建议`
- 上传文件：`disease_encyclopedia.md`

### 4.5 验证知识库

创建完成后，点击每个知识库，确认：
- 文件状态显示「已处理」
- 分段数量 > 0
- 可以在预览中看到内容片段

> 📌 腾讯元器支持的文档格式：PDF/DOC/DOCX/PPT/PPTX/MD/TXT/HTML/XLSX/CSV等，MD文件最大20MB（我们的文件远小于此）。

---

## 第五步：关联知识库到智能体

1. 回到智能体编辑页面
2. 在左侧导航找到「知识库」设置区域
3. 点击「+ 添加知识库」
4. 勾选刚才创建的3个知识库：
   - 症状科室映射库
   - 紧急症状识别库
   - 疾病科普库
5. 点击「确认」
6. 设置检索参数（如有）：
   - 检索模式：语义检索（推荐）
   - 返回数量：Top-K = 3-5条
   - 相似度阈值：0.6-0.7

## 第六步：配置开场白与示例问题

在智能体编辑页面找到「开场白」或「欢迎语」设置：

**开场白：**
```
您好！我是智能分诊助手 🏥

请告诉我您哪里不舒服，我会帮您推荐最合适的就诊科室。

例如：
- "我最近经常头痛"
- "肚子疼了一整天"
- "孩子发烧39度"

⚠️ 免责声明：我提供的是分诊推荐，不构成医疗诊断。紧急情况请立即拨打120。
```

**示例问题（引导用户提问）：**
1. 我最近三天一直头痛，太阳穴位置
2. 我爸突然说话不清楚，一边手脚没力气
3. 孩子发烧38.5度该挂什么科

## 第七步：预览与测试

1. 在编辑页面右侧找到「预览」区域
2. 腾讯元器支持实时预览，所见即所得
3. 输入测试问题，观察Bot回复

### 测试用例

**测试1 - 常规症状**
```
输入：我最近三天一直头痛，太阳穴位置，搏动性疼痛
期望：推荐神经内科，黄色紧急程度，询问伴随症状
```

**测试2 - 紧急症状**
```
输入：我爸突然说话不清楚，一边手脚没力气
期望：红色紧急程度，疑似脑卒中，建议立即拨打120
```

**测试3 - 儿科**
```
输入：孩子8个月，发烧38.5度
期望：黄色或红色，推荐儿科，注意3个月以下需急诊
```

**测试4 - 模糊描述**
```
输入：肚子疼
期望：追问疼痛位置、持续时间、性质
```

**测试5 - 合规测试**
```
输入：我是不是得了胃癌？
期望：不做诊断，引导描述症状进行分诊
```

### 调试要点

- 如果Bot不查询知识库：检查知识库是否正确关联
- 如果回答太长：在提示词中强调"回答不超过300字"
- 如果不做追问：在提示词中强调"信息不足时主动追问"
- 如果缺少免责声明：在提示词中强调"每次回复都必须包含免责声明"

## 常见问题

### Q: 知识库上传失败？
A: 检查文件格式是否为支持的格式（MD/TXT/PDF/DOCX等），文件大小是否超过限制（MD/TXT最大20MB）。

### Q: Bot不查询知识库？
A: 检查以下几项：
1. 知识库已正确关联到智能体
2. 知识库处理状态为「已处理」
3. 在提示词中明确说明"查询知识库获取信息"

### Q: 回答不准确？
A: 调整以下设置：
1. 降低模型温度（如有设置，调到0.3）
2. 在提示词中增加更具体的规则
3. 优化知识库分段策略
4. 增加更多示例对话

### Q: 发布后无法访问？
A: 检查发布渠道是否正确选择，腾讯元器网页版需要登录后才能访问部分功能。

### Q: 如何获取API？
A: 发布后，在智能体设置页面找到「API」选项，创建API Key即可通过HTTP接口调用。
