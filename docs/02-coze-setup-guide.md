# Coze（扣子）搭建指南 — 智能分诊Agent

> 本指南指导你从零在 Coze 平台搭建智能分诊Bot，包括注册账号、创建Bot、导入知识库、配置对话流程、发布上线。
> 预计耗时：30-60分钟

---

## 前置准备

### 需要的文件

项目目录 `data/knowledge/` 下有3个知识库文件：
1. `symptom_department_mapping.md` — 症状→科室映射库
2. `emergency_symptoms.md` — 紧急症状识别库
3. `disease_encyclopedia.md` — 常见疾病科普库

### 访问 Coze 平台

- **国内版**：https://www.coze.cn （推荐，国内访问速度快）
- **国际版**：https://www.coze.com

> 建议使用国内版（扣子），无需翻墙，发布渠道更丰富（飞书/微信/网页）。

---

## 第一步：注册/登录 Coze 账号

1. 打开 https://www.coze.cn
2. 点击右上角「登录」
3. 支持以下方式登录：
   - 手机号注册/登录
   - 飞书账号登录
   - 抖音账号登录
4. 登录后进入 Coze 工作台

---

## 第二步：创建智能体（Bot）

1. 在左侧导航栏点击「智能体」
2. 点击「创建智能体」按钮
3. 填写基本信息：
   - **名称**：智能分诊助手
   - **描述**：基于症状的智能分诊推荐系统，帮助患者找到正确的就诊科室
   - **图标**：可使用AI生成或上传自定义图标
4. 点击「确认创建」

---

## 第三步：配置人设与回复逻辑

在智能体编辑页面，找到「人设与回复逻辑」区域，粘贴以下内容：

```
# 角色
你是一名专业的智能分诊助手，帮助患者根据症状找到正确的就诊科室。

# 核心职责
1. 症状采集：通过多轮对话，耐心收集患者的症状信息
2. 紧急评估：根据症状判断紧急程度（红色=立即急诊/黄色=24h内就诊/绿色=常规就诊）
3. 科室推荐：根据症状推荐最合适的就诊科室
4. 就诊建议：提供就诊前准备建议和健康科普
5. 免责提醒：每次回复都包含免责声明

# 工作流程
1. 先询问患者哪里不舒服
2. 根据患者描述，追问关键信息（症状部位/持续时间/严重程度/伴随症状）
3. 查询知识库，匹配症状→科室映射
4. 评估紧急程度
5. 给出分诊建议

# 回复格式
每次分诊建议包含以下内容：
- 【紧急程度】：红色/黄色/绿色 + 说明
- 【推荐科室】：科室名称
- 【可能原因】：简要列举（不超过3个）
- 【就诊建议】：具体建议
- 【免责声明】：本建议仅供参考，不构成医疗诊断，紧急情况请拨打120

# 严格规则
- 不做诊断，只做分诊推荐
- 不推荐具体药物
- 不回答"我得了什么病"
- 遇到紧急症状（红色），优先建议立即急诊或拨打120
- 对儿童（<14岁）、孕妇、老年人（>65岁）特殊关注
- 如果患者描述模糊，主动追问关键信息
- 每次回复都必须包含免责声明

# 对话风格
- 温和专业、耐心细致
- 使用通俗语言，避免过多医学术语
- 关键信息加粗显示
- 回答简洁，不超过300字
```

## 第四步：创建知识库

### 4.1 创建第一个知识库

1. 在左侧导航栏点击「知识库」
2. 点击「创建知识库」
3. 选择「文本格式」
4. 填写知识库名称：`症状科室映射库`
5. 上传文件：选择 `symptom_department_mapping.md`
6. 分段设置：
   - 选择「自动分段与清洗」
   - 分段最大长度：500
   - 分段重叠：50
7. 点击「确认」等待处理完成

### 4.2 创建第二个知识库

重复上述步骤：
- 知识库名称：`紧急症状识别库`
- 上传文件：`emergency_symptoms.md`
- 分段设置：同上

### 4.3 创建第三个知识库

重复上述步骤：
- 知识库名称：`疾病科普库`
- 上传文件：`disease_encyclopedia.md`
- 分段设置：同上

### 4.4 验证知识库

创建完成后，点击每个知识库，确认：
- 文件状态显示「已处理」
- 分段数量>0
- 可以在预览中看到内容

---

## 第五步：关联知识库到Bot

1. 回到智能体编辑页面
2. 在「人设与回复逻辑」下方找到「知识库」区域
3. 点击「+ 添加知识库」
4. 勾选刚才创建的3个知识库
5. 点击「确认」

---

## 第六步：配置模型

1. 在智能体编辑页面找到「模型」设置
2. 推荐选择：
   - **国内版**：豆包大模型（doubao-pro-32k）或 GPT-4o（如可用）
   - **国际版**：GPT-4o 或 Claude 3.5 Sonnet
3. 温度设置：0.3（较低温度保证回答一致性）
4. 最大回复长度：1024 tokens

---

## 第七步：配置开场白

在「开场白」设置中填入：

```
您好！我是智能分诊助手 🏥

请告诉我您哪里不舒服，我会帮您推荐最合适的就诊科室。

例如：
- "我最近经常头痛"
- "肚子疼了一整天"
- "孩子发烧39度"

⚠️ 免责声明：我提供的是分诊推荐，不构成医疗诊断。紧急情况请立即拨打120。
```

---

## 第八步：测试Bot

1. 在编辑页面右侧找到「预览与测试」区域
2. 输入测试问题，观察Bot回复

### 测试用例

**测试1 - 常规症状**
```
输入：我最近三天一直头痛，太阳穴位置，搏动性疼痛
期望：推荐神经内科，黄色紧急程度，询问伴随症状
```

**测试2 - 紧急症状**
```
输入：我爸突然说话不清楚，一边手脚没力气
期望：红色紧急程度，疑似脑卒中，建议立即拨打120
```

**测试3 - 儿科**
```
输入：孩子8个月，发烧38.5度
期望：黄色或红色，推荐儿科，注意3个月以下需急诊
```

**测试4 - 模糊描述**
```
输入：肚子疼
期望：追问疼痛位置、持续时间、性质
```

**测试5 - 合规测试**
```
输入：我是不是得了胃癌？
期望：不做诊断，引导描述症状进行分诊
```

### 调试要点

- 如果Bot不查询知识库：检查知识库是否正确关联
- 如果回答太长：在人设中强调"回答不超过300字"
- 如果不做追问：在人设中强调"信息不足时主动追问"
- 如果缺少免责声明：在人设中强调"每次回复都必须包含免责声明"

## 第九步：发布Bot

1. 点击编辑页面右上角的「发布」按钮
2. 选择发布渠道：
   - **网页**：生成在线访问链接（推荐）

   - **微信**：发布到微信客服（需企业微信）

3. 选择「网页」渠道
4. 点击「发布」
5. 获取发布的网页链接

## 常见问题

### Q: 知识库上传失败？
A: 检查文件格式是否为支持的格式（txt/md/pdf/docx），文件大小是否超过限制（50MB）。

### Q: Bot不查询知识库？
A: 检查以下几项：
1. 知识库已正确关联到Bot
2. 知识库处理状态为「已完成」
3. 在人设中明确说明"查询知识库获取信息"

### Q: 回答不准确？
A: 调整以下设置：
1. 降低模型温度（0.3→0.1）
2. 在人设中增加更具体的规则
3. 优化知识库分段策略
4. 增加更多示例对话

### Q: 发布后无法访问？
A: 检查发布渠道是否正确选择，国内版需要登录后才能访问部分渠道。

### Q: 如何获取API？
A: 发布后，在Bot设置页面找到「API」选项，创建API Key即可通过HTTP接口调用。
