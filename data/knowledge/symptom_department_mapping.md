# 症状-科室映射知识库

> 本知识库用于智能分诊Agent，根据患者描述的症状推荐就诊科室。
> 覆盖12大身体系统、220+常见症状，每个症状包含推荐科室、可能疾病、紧急程度和就诊建议。

## 紧急程度说明

- **红色（立即急诊）**：危及生命，需拨打120或立即前往急诊科
- **黄色（24h内就诊）**：需尽快就医，可预约当日门诊
- **绿色（常规就诊）**：可预约普通门诊，无需紧急处理

## 一、头颈部症状

### 1. 头痛
- 推荐科室：神经内科
- 可能疾病：偏头痛、紧张性头痛、高血压、脑血管疾病
- 紧急程度：黄色（若伴呕吐/意识模糊/剧烈加重→红色）
- 就诊建议：记录头痛频率、持续时间、诱因

### 2. 头晕/眩晕
- 推荐科室：神经内科 / 耳鼻喉科
- 可能疾病：良性阵发性位置性眩晕（耳石症）、颈椎病、脑供血不足
- 紧急程度：黄色（若伴言语不清/肢体无力→红色）
- 就诊建议：描述头晕性质（旋转感/昏沉感）

### 3. 视力模糊/下降
- 推荐科室：眼科
- 可能疾病：近视、白内障、青光眼、糖尿病视网膜病变
- 紧急程度：黄色（突发失明→红色）
- 就诊建议：说明发生时间、单眼/双眼

### 4. 眼红/眼痛
- 推荐科室：眼科
- 可能疾病：结膜炎、角膜炎、青光眼急性发作
- 紧急程度：黄色（剧烈眼痛+头痛+恶心→红色，疑似急性闭角型青光眼）
- 就诊建议：勿自行使用眼药水

### 5. 耳鸣
- 推荐科室：耳鼻喉科
- 可能疾病：神经性耳鸣、中耳炎、噪声损伤
- 紧急程度：绿色
- 就诊建议：描述耳鸣声音（嗡嗡/蝉鸣）

### 6. 耳痛/听力下降
- 推荐科室：耳鼻喉科
- 可能疾病：中耳炎、外耳道炎、突发性耳聋
- 紧急程度：黄色（突发听力下降→24h内就诊）
- 就诊建议：突发性耳聋黄金治疗期为72小时

### 7. 鼻塞/流涕
- 推荐科室：耳鼻喉科 / 呼吸内科
- 可能疾病：鼻炎、鼻窦炎、上呼吸道感染
- 紧急程度：绿色
- 就诊建议：描述分泌物性状（清/脓/血性）

### 8. 鼻出血
- 推荐科室：耳鼻喉科
- 可能疾病：鼻腔干燥、鼻外伤、高血压、血液病
- 紧急程度：黄色（大量出血不止→红色）
- 就诊建议：出血时前倾低头、捏鼻翼压迫止血

### 9. 咽痛/吞咽困难
- 推荐科室：耳鼻喉科 / 呼吸内科
- 可能疾病：咽炎、扁桃体炎、会厌炎
- 紧急程度：黄色（呼吸困难→红色，疑似急性会厌炎）
- 就诊建议：急性会厌炎可致窒息，需紧急处理

### 10. 声音嘶哑
- 推荐科室：耳鼻喉科
- 可能疾病：声带息肉、喉炎、甲状腺疾病
- 紧急程度：绿色（超过2周不愈→黄色）
- 就诊建议：长期声嘶需排除喉部肿瘤

### 11. 牙痛
- 推荐科室：口腔科
- 可能疾病：龋齿、牙髓炎、根尖周炎、智齿冠周炎
- 紧急程度：黄色（面部肿胀→红色）
- 就诊建议：描述疼痛性质（冷热刺激痛/自发痛/咬合痛）

### 12. 面部麻木/口角歪斜
- 推荐科室：神经内科
- 可能疾病：面神经炎（贝尔麻痹）、脑卒中
- 紧急程度：红色（可能是脑卒中，需立即急诊）
- 就诊建议：鉴别中枢性与周围性面瘫

### 13. 面部肿胀
- 推荐科室：口腔颌面外科 / 皮肤科
- 可能疾病：牙源性感染、腮腺炎、过敏反应
- 紧急程度：黄色（伴呼吸困难→红色）
- 就诊建议：说明肿胀发生速度

### 14. 颈部肿块
- 推荐科室：甲状腺外科 / 耳鼻喉科 / 普外科
- 可能疾病：淋巴结肿大、甲状腺结节、腮腺肿瘤
- 紧急程度：黄色
- 就诊建议：说明肿块大小、硬度、活动度

### 15. 颈部疼痛/活动受限
- 推荐科室：骨科 / 疼痛科
- 可能疾病：颈椎病、落枕、颈肌劳损
- 紧急程度：绿色（伴上肢麻木→黄色）
- 就诊建议：描述疼痛放射范围

### 16. 眼干/眼疲劳
- 推荐科室：眼科
- 可能疾病：干眼症、视疲劳、睑板腺功能障碍
- 紧急程度：绿色
- 就诊建议：减少屏幕时间，人工泪液缓解

### 17. 飞蚊症/眼前黑影
- 推荐科室：眼科
- 可能疾病：玻璃体混浊、视网膜裂孔、玻璃体后脱离
- 紧急程度：黄色（伴闪光感/视野缺损→红色）
- 就诊建议：突然增多需排查视网膜病变

### 18. 复视/视物重影
- 推荐科室：眼科 / 神经内科
- 可能疾病：眼肌麻痹、脑卒中、重症肌无力
- 紧急程度：黄色（突发复视→红色，排查脑血管）
- 就诊建议：描述单眼/双眼复视

### 19. 麦粒肿/霰粒肿
- 推荐科室：眼科
- 可能疾病：睑腺炎、睑板腺囊肿
- 紧急程度：绿色
- 就诊建议：热敷，化脓需眼科处理

### 20. 嗅觉减退/丧失
- 推荐科室：耳鼻喉科 / 神经内科
- 可能疾病：鼻炎、上呼吸道感染、嗅神经病变
- 紧急程度：绿色
- 就诊建议：突然嗅觉丧失需排查神经原因

### 21. 味觉异常/丧失
- 推荐科室：耳鼻喉科 / 神经内科
- 可能疾病：锌缺乏、舌炎、嗅味觉神经损伤
- 紧急程度：绿色
- 就诊建议：描述味觉变化类型

### 22. 舌痛/舌麻/舌炎
- 推荐科室：口腔科 / 风湿免疫科
- 可能疾病：灼口综合征、萎缩性舌炎、维生素缺乏
- 紧急程度：绿色
- 就诊建议：长期不愈需排查系统性疾病

### 23. 牙龈出血/牙龈肿痛
- 推荐科室：口腔科
- 可能疾病：牙龈炎、牙周炎、血液病
- 紧急程度：绿色（伴出血不止→黄色）
- 就诊建议：定期洁牙，检查血常规

### 24. 牙周病/牙齿松动
- 推荐科室：口腔科
- 可能疾病：牙周炎、骨质疏松
- 紧急程度：绿色
- 就诊建议：牙周系统治疗

### 25. 颞下颌关节紊乱
- 推荐科室：口腔科 / 疼痛科
- 可能疾病：颞下颌关节紊乱综合征
- 紧急程度：绿色
- 就诊建议：避免咀嚼硬物，热敷

### 26. 腮腺肿大/腮腺痛
- 推荐科室：口腔科 / 感染科
- 可能疾病：腮腺炎、腮腺导管结石、腮腺肿瘤
- 紧急程度：黄色
- 就诊建议：流行性腮腺炎有传染性

### 27. 持续性打喷嚏
- 推荐科室：耳鼻喉科
- 可能疾病：过敏性鼻炎、血管运动性鼻炎
- 紧急程度：绿色
- 就诊建议：远离过敏原，鼻腔冲洗

### 28. 口臭
- 推荐科室：口腔科 / 消化内科
- 可能疾病：牙周病、幽门螺杆菌感染、消化不良
- 紧急程度：绿色
- 就诊建议：排查口腔与胃肠原因

### 29. 颈部僵硬/活动受限伴发热
- 推荐科室：神经内科 / 感染科
- 可能疾病：脑膜炎、颈椎感染
- 紧急程度：红色（颈强直+高热→疑似脑膜炎）
- 就诊建议：立即急诊

### 30. 腮腺区反复肿胀
- 推荐科室：口腔科
- 可能疾病：慢性阻塞性腮腺炎、涎石症
- 紧急程度：绿色
- 就诊建议：进食时肿胀加重提示导管阻塞

## 二、胸部与乳腺症状

### 31. 胸痛
- 推荐科室：急诊科 / 心内科
- 可能疾病：心绞痛、心肌梗死、肺栓塞、主动脉夹层、肋间神经痛
- 紧急程度：红色（剧烈胸痛/放射至左肩/伴出汗→立即急诊）
- 就诊建议：心源性胸痛可致命，宁可谨慎

### 32. 胸闷/憋气
- 推荐科室：心内科 / 呼吸内科
- 可能疾病：冠心病、心力衰竭、哮喘、肺气肿
- 紧急程度：黄色（静息状态下胸闷→红色）
- 就诊建议：描述诱发因素（活动/情绪/体位）

### 33. 心悸
- 推荐科室：心内科
- 可能疾病：心律失常、甲状腺功能亢进、贫血、焦虑
- 紧急程度：黄色（伴胸痛/晕厥→红色）
- 就诊建议：记录发作频率和持续时间

### 34. 咳嗽
- 推荐科室：呼吸内科
- 可能疾病：上呼吸道感染、支气管炎、肺炎、咳嗽变异性哮喘
- 紧急程度：绿色（伴咯血/呼吸困难→红色）
- 就诊建议：描述咳嗽性质（干咳/湿咳）

### 35. 咳痰
- 推荐科室：呼吸内科
- 可能疾病：支气管炎、肺炎、支气管扩张
- 紧急程度：绿色（大量脓痰/血痰→黄色）
- 就诊建议：描述痰液颜色和量

### 36. 咯血
- 推荐科室：呼吸内科 / 急诊科
- 可能疾病：肺结核、支气管扩张、肺癌、肺栓塞
- 紧急程度：红色
- 就诊建议：立即就医，保持患侧卧位

### 37. 气短/呼吸困难
- 推荐科室：呼吸内科 / 急诊科
- 可能疾病：哮喘急性发作、肺栓塞、心力衰竭、气胸
- 紧急程度：红色
- 就诊建议：立即就医或拨打120

### 38. 背部疼痛
- 推荐科室：骨科 / 心内科
- 可能疾病：肌肉劳损、脊柱疾病、心绞痛放射痛
- 紧急程度：黄色（撕裂样背痛→红色，疑似主动脉夹层）
- 就诊建议：描述疼痛位置和性质

### 39. 心前区不适/压榨感
- 推荐科室：心内科 / 急诊科
- 可能疾病：心绞痛、心肌缺血、反流性食管炎
- 紧急程度：红色（压榨感+活动诱发→立即急诊）
- 就诊建议：含服硝酸甘油不缓解立即就医

### 40. 胸骨后疼痛
- 推荐科室：心内科 / 消化内科
- 可能疾病：食管炎、心绞痛、食管痉挛
- 紧急程度：黄色（与进食相关→消化内科）
- 就诊建议：鉴别心源性与食管源性

### 41. 喘息/哮鸣音
- 推荐科室：呼吸内科
- 可能疾病：哮喘、慢阻肺急性加重、支气管异物
- 紧急程度：黄色（严重喘息伴呼吸困难→红色）
- 就诊建议：急性发作立即使用急救吸入剂

### 42. 反复胸闷夜间憋醒
- 推荐科室：心内科 / 呼吸内科
- 可能疾病：心力衰竭、睡眠呼吸暂停
- 紧急程度：黄色（端坐呼吸→红色）
- 就诊建议：记录夜间发作情况

### 43. 乳房肿块
- 推荐科室：乳腺外科 / 普外科
- 可能疾病：纤维腺瘤、乳腺增生、乳腺癌
- 紧急程度：黄色（无痛性硬块→需排查）
- 就诊建议：定期自检，超声/钼靶检查

### 44. 乳房疼痛
- 推荐科室：乳腺外科 / 普外科
- 可能疾病：乳腺增生、乳腺炎、经前综合征
- 紧急程度：绿色（哺乳期红肿热痛→黄色）
- 就诊建议：描述与月经周期关系

### 45. 乳头溢液
- 推荐科室：乳腺外科 / 内分泌科
- 可能疾病：导管内乳头状瘤、泌乳素瘤、乳腺增生
- 紧急程度：黄色（血性溢液→需排查）
- 就诊建议：描述溢液颜色、单/双侧

### 46. 乳腺皮肤改变/凹陷
- 推荐科室：乳腺外科
- 可能疾病：乳腺癌（酒窝征/橘皮样变）
- 紧急程度：黄色
- 就诊建议：尽快就诊排查恶性肿瘤

### 47. 胸腔积液/胸水
- 推荐科室：呼吸内科 / 胸外科
- 可能疾病：结核性胸膜炎、恶性肿瘤、心衰
- 紧急程度：黄色（大量积液呼吸困难→红色）
- 就诊建议：需胸水穿刺化验

### 48. 乳房红肿发热（哺乳期）
- 推荐科室：乳腺外科
- 可能疾病：急性乳腺炎、乳汁淤积
- 紧急程度：黄色（化脓发热→需处理）
- 就诊建议：通畅排乳，必要时抗生素

## 三、腹部与消化道症状

### 49. 腹痛
- 推荐科室：消化内科 / 普外科 / 急诊科
- 可能疾病：胃肠炎、阑尾炎、胆囊炎、胰腺炎、肠梗阻
- 紧急程度：黄色（剧烈腹痛/板状腹/伴呕吐→红色）
- 就诊建议：描述疼痛位置（上腹/下腹/全腹）

### 50. 腹胀
- 推荐科室：消化内科
- 可能疾病：消化不良、肠道菌群失调、腹水
- 紧急程度：绿色（伴腹痛/呕吐→黄色）
- 就诊建议：说明饮食相关因素

### 51. 恶心/呕吐
- 推荐科室：消化内科 / 急诊科
- 可能疾病：胃肠炎、食物中毒、妊娠反应、颅内压增高
- 紧急程度：黄色（喷射性呕吐/伴头痛→红色）
- 就诊建议：说明呕吐物性状

### 52. 腹泻
- 推荐科室：消化内科 / 肠道门诊
- 可能疾病：急性胃肠炎、食物中毒、炎症性肠病
- 紧急程度：绿色（大量水样便/血便/伴脱水→黄色）
- 就诊建议：注意补充水分和电解质

### 53. 便秘
- 推荐科室：消化内科
- 可能疾病：功能性便秘、肠梗阻、甲状腺功能减退
- 紧急程度：绿色（伴腹痛/腹胀/呕吐→黄色）
- 就诊建议：说明排便习惯变化

### 54. 便血
- 推荐科室：消化内科 / 肛肠外科
- 可能疾病：痔疮、肛裂、炎症性肠病、结直肠肿瘤
- 紧急程度：黄色（大量便血→红色）
- 就诊建议：描述血液颜色（鲜红/暗红/柏油样）

### 55. 吞咽困难
- 推荐科室：消化内科 / 耳鼻喉科
- 可能疾病：食管狭窄、食管癌、贲门失弛缓症
- 紧急程度：黄色
- 就诊建议：说明固体/液体吞咽困难

### 56. 胃灼热/反酸
- 推荐科室：消化内科
- 可能疾病：胃食管反流病、胃炎、消化性溃疡
- 紧急程度：绿色
- 就诊建议：说明与饮食/体位的关系

### 57. 食欲下降
- 推荐科室：消化内科
- 可能疾病：消化系统疾病、甲状腺功能减退、抑郁症
- 紧急程度：绿色（伴消瘦→黄色）
- 就诊建议：记录体重变化

### 58. 右上腹痛
- 推荐科室：肝胆外科 / 消化内科
- 可能疾病：胆囊炎、胆结石、肝炎
- 紧急程度：黄色（剧烈绞痛→急诊）
- 就诊建议：说明与进食油腻食物的关系

### 59. 左下腹痛
- 推荐科室：消化内科 / 肛肠外科
- 可能疾病：结肠炎、憩室炎、肠道肿瘤
- 紧急程度：黄色
- 就诊建议：说明排便与疼痛的关系

### 60. 嗳气/打嗝（功能性）

## 六、全身症状

### 116. 发热
- 推荐科室：发热门诊 / 呼吸内科 / 感染科
- 可能疾病：上呼吸道感染、肺炎、泌尿系感染、败血症
- 紧急程度：黄色（体温>39.5度/伴意识改变→红色）
- 就诊建议：记录体温曲线、热型

### 117. 高热
- 推荐科室：急诊科 / 发热门诊
- 可能疾病：重症感染、热射病
- 紧急程度：红色（体温>40度/伴抽搐→立即急诊）
- 就诊建议：物理降温，立即就医

### 118. 乏力/疲劳
- 推荐科室：全科 / 内分泌科
- 可能疾病：贫血、甲状腺功能减退、慢性疲劳综合征、抑郁症
- 紧急程度：绿色（伴消瘦/发热→黄色）
- 就诊建议：说明持续时间

### 119. 消瘦/体重下降
- 推荐科室：全科 / 肿瘤科 / 内分泌科
- 可能疾病：恶性肿瘤、糖尿病、甲状腺功能亢进
- 紧急程度：黄色（6个月内体重下降>5%需排查）
- 就诊建议：记录体重变化趋势

### 120. 水肿
- 推荐科室：肾内科 / 心内科
- 可能疾病：肾病综合征、心力衰竭、肝功能不全
- 紧急程度：黄色
- 就诊建议：描述水肿部位（下肢/眼睑/全身）

### 121. 盗汗

- 可能疾病：结核病、淋巴瘤、甲状腺功能亢进

- 就诊建议：记录盗汗频率

### 122. 畏寒/寒战

### 123. 面色苍白

### 124. 淋巴结肿大

### 125. 低热（37.3-38度）

### 194. 雷诺现象（肢端发白发紫）
- 推荐科室：风湿免疫科
- 可能疾病：系统性硬化、红斑狼疮、原发性雷诺
- 紧急程度：绿色
- 就诊建议：保暖，免疫指标

### 195. 反复发热伴关节肿痛
- 推荐科室：风湿免疫科 / 感染科
- 可能疾病：风湿热、成人Still病、感染
- 紧急程度：黄色
- 就诊建议：炎症指标+培养

## 十一、儿童与孕产妇症状

### 196. 儿童发热
- 推荐科室：儿科 / 儿科急诊
- 可能疾病：上呼吸道感染、手足口病、肺炎
- 紧急程度：黄色（3个月以下婴儿发热/体温>39度→红色）
- 就诊建议：3个月以下婴儿发热需立即就医

### 197. 儿童咳嗽
- 推荐科室：儿科
- 可能疾病：上呼吸道感染、支气管炎、肺炎、异物吸入
- 紧急程度：绿色（伴呼吸困难/犬吠样咳嗽→黄色）
- 就诊建议：注意观察呼吸频率

### 198. 儿童腹泻
- 推荐科室：儿科
- 可能疾病：病毒性肠炎、细菌性肠炎
- 紧急程度：黄色（伴脱水→红色）
- 就诊建议：注意补充口服补液盐

### 199. 儿童皮疹
- 推荐科室：儿科 / 皮肤科
- 可能疾病：湿疹、幼儿急疹、手足口病、水痘
- 紧急程度：黄色（伴高热/精神差→红色）
- 就诊建议：观察精神状态

### 200. 儿童腹痛
- 推荐科室：儿科 / 小儿外科
- 可能疾病：肠痉挛、肠系膜淋巴结炎、阑尾炎
- 紧急程度：黄色（持续加剧/拒按→红色）
- 就诊建议：注意有无手术指征

### 201. 儿童呕吐
- 推荐科室：儿科
- 可能疾病：胃肠炎、幽门梗阻、颅内压增高
- 紧急程度：黄色（喷射性/伴头痛→红色）
- 就诊建议：防脱水

### 202. 儿童黄疸
- 推荐科室：儿科 / 新生儿科
- 可能疾病：新生儿黄疸、胆道闭锁、肝炎
- 紧急程度：黄色（新生儿黄疸加重→红色）
- 就诊建议：胆红素监测

### 203. 儿童抽搐/热性惊厥
- 推荐科室：儿科 / 急诊科
- 可能疾病：热性惊厥、癫痫、脑炎
- 紧急程度：红色
- 就诊建议：侧卧防误吸，立即就医

### 204. 儿童发育落后
- 推荐科室：儿科 / 儿童保健科
- 可能疾病：发育迟缓、自闭症谱系、脑瘫
- 紧急程度：黄色
- 就诊建议：发育筛查评估

### 205. 儿童喘息/哮鸣
- 推荐科室：儿科 / 呼吸科
- 可能疾病：毛细支气管炎、哮喘、异物吸入
- 紧急程度：黄色（呼吸困难→红色）
- 就诊建议：雾化治疗

### 206. 孕妇不适（恶心/乏力）
- 推荐科室：产科
- 可能疾病：妊娠反应、妊娠并发症
- 紧急程度：黄色（阴道出血/腹痛/胎动减少→红色）
- 就诊建议：孕妇用药需遵医嘱

### 207. 孕妇水肿
- 推荐科室：产科
- 可能疾病：妊娠期生理水肿、子痫前期
- 紧急程度：黄色（伴高血压/蛋白尿→红色）
- 就诊建议：监测血压

### 208. 孕妇高血压/头晕
- 推荐科室：产科 / 急诊科
- 可能疾病：妊娠期高血压、子痫前期
- 紧急程度：红色（伴头痛/视物模糊→子痫前期）
- 就诊建议：立即就医

### 209. 胎动异常（过多/过少）
- 推荐科室：产科 / 急诊科
- 可能疾病：胎儿窘迫
- 紧急程度：红色
- 就诊建议：立即胎心监护

### 210. 产前阴道出血
- 推荐科室：产科 / 急诊科
- 可能疾病：前置胎盘、胎盘早剥
- 紧急程度：红色
- 就诊建议：立即平卧就医

### 211. 产后发热/伤口痛
- 推荐科室：产科
- 可能疾病：产褥感染、伤口感染
- 紧急程度：黄色（高热→红色）
- 就诊建议：抗生素治疗

### 212. 哺乳期乳房硬块/发热
- 推荐科室：乳腺外科 / 产科
- 可能疾病：急性乳腺炎、乳汁淤积
- 紧急程度：黄色
- 就诊建议：通畅排乳

### 213. 新生儿不吃/不哭/反应差
- 推荐科室：新生儿科 / 急诊科
- 可能疾病：新生儿感染、代谢病、窒息
- 紧急程度：红色
- 就诊建议：立即新生儿科就诊

## 十二、老年与慢性病患者症状

### 214. 老年人跌倒
- 推荐科室：急诊科 / 老年医学科
- 可能疾病：骨折、脑出血、晕厥
- 紧急程度：黄色（头部着地/意识改变→红色）
- 就诊建议：老年人跌倒需排查骨折和颅内出血

### 215. 老年人认知下降/迷路
- 推荐科室：老年医学科 / 神经内科
- 可能疾病：阿尔茨海默病、血管性痴呆
- 紧急程度：黄色
- 就诊建议：认知量表评估

### 216. 老年人尿失禁/夜尿多
- 推荐科室：泌尿外科 / 老年医学科
- 可能疾病：前列腺增生、神经源性膀胱、老年弱化
- 紧急程度：绿色
- 就诊建议：评估可逆因素

### 217. 多重用药/药物相互作用
- 推荐科室：老年医学科 / 药学门诊
- 可能疾病：药物不良反应、相互作用
- 紧急程度：黄色
- 就诊建议：用药清单整理

### 218. 慢性病患者症状突然加重
- 推荐科室：相应专科 / 急诊科
- 可能疾病：慢阻肺急性加重、心衰加重、糖尿病酮症
- 紧急程度：黄色（呼吸困难/意识障碍→红色）
- 就诊建议：携带病历与用药史

### 219. 术后不适/伤口问题
- 推荐科室：手术科室 / 外科
- 可能疾病：术后感染、伤口愈合不良
- 紧急程度：黄色（发热/伤口红肿→需检查）
- 就诊建议：说明手术类型和时间

### 220. 长期卧床并发症（压疮/血栓）
- 推荐科室：老年医学科 / 创面门诊 / 血管外科
- 可能疾病：压疮、深静脉血栓、坠积性肺炎
- 紧急程度：黄色
- 就诊建议：定期翻身，预防血栓

## 十三、症状交叉索引（按科室反查）

### 内科系统
- **心内科**：胸痛、胸闷、心悸、晕厥、水肿、心前区不适
- **呼吸内科**：咳嗽、咳痰、咯血、气短、打鼾、喘息
- **消化内科**：腹痛、腹胀、恶心呕吐、腹泻、便血、胃灼热
- **神经内科**：头痛、头晕、肢体麻木/无力、抽搐、言语障碍
- **内分泌科**：消瘦、乏力、甲状腺肿大、多饮多尿、怕热多汗
- **肾内科**：血尿、蛋白尿、水肿、尿量异常、夜尿增多
- **血液科**：贫血、出血倾向、淋巴结肿大、紫癜
- **风湿免疫科**：关节疼痛/肿胀、肌肉疼痛、口干眼干、雷诺现象
- **感染科/发热门诊**：发热、寒战、不明原因感染

### 外科系统
- **普外科**：急腹症、腹部肿块、乳腺肿块、疝
- **骨科**：骨折、关节脱位、腰背痛、颈椎病、关节疼痛
- **泌尿外科**：泌尿系结石、前列腺疾病、阴囊肿块、排尿困难
- **神经外科**：颅内肿瘤、脑出血、脊髓病变
- **心胸外科**：心脏手术、肺部手术、食管手术
- **血管外科**：下肢静脉曲张、深静脉血栓、动脉硬化、肢体发凉

### 专科系统
- **眼科**：视力问题、眼红眼痛、飞蚊症、复视
- **耳鼻喉科**：耳痛耳鸣、鼻塞鼻出血、咽痛声嘶、嗅觉异常
- **口腔科**：牙痛、口腔溃疡、颌面部肿胀、颞下颌关节
- **皮肤科**：皮疹、瘙痒、皮肤溃疡、脱发、银屑病
- **乳腺外科**：乳房肿块、乳头溢液、乳腺炎
- **妇科**：月经异常、阴道出血、白带异常、下腹痛
- **儿科**：儿童发热、咳嗽、腹泻、发育异常
- **精神科**：失眠、焦虑、抑郁、认知障碍、幻觉妄想
- **肿瘤科**：不明原因消瘦、肿块、持续疼痛
- **老年医学科**：老年人多病共存、跌倒、用药管理
- **康复科**：脑卒中康复、术后康复、慢性疼痛
