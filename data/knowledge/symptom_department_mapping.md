# 症状-科室映射知识库

> 本知识库用于智能分诊Agent，根据患者描述的症状推荐就诊科室。
> 覆盖8大身体部位、300+常见症状，每个症状包含推荐科室、可能疾病、紧急程度和就诊建议。

## 紧急程度说明

- **红色（立即急诊）**：危及生命，需拨打120或立即前往急诊科
- **黄色（24h内就诊）**：需尽快就医，可预约当日门诊
- **绿色（常规就诊）**：可预约普通门诊，无需紧急处理

## 一、头颈部症状

### 1. 头痛
- 推荐科室：神经内科
- 可能疾病：偏头痛、紧张性头痛、高血压、脑血管疾病
- 紧急程度：黄色（若伴呕吐/意识模糊/剧烈加重→红色）
- 就诊建议：记录头痛频率、持续时间、诱因

### 2. 头晕/眩晕
- 推荐科室：神经内科 / 耳鼻喉科
- 可能疾病：良性阵发性位置性眩晕（耳石症）、颈椎病、脑供血不足
- 紧急程度：黄色（若伴言语不清/肢体无力→红色）
- 就诊建议：描述头晕性质（旋转感/昏沉感）

### 3. 视力模糊/下降
- 推荐科室：眼科
- 可能疾病：近视、白内障、青光眼、糖尿病视网膜病变
- 紧急程度：黄色（突发失明→红色）
- 就诊建议：说明发生时间、单眼/双眼

### 4. 眼红/眼痛
- 推荐科室：眼科
- 可能疾病：结膜炎、角膜炎、青光眼急性发作
- 紧急程度：黄色（剧烈眼痛+头痛+恶心→红色，疑似急性闭角型青光眼）
- 就诊建议：勿自行使用眼药水

### 5. 耳鸣
- 推荐科室：耳鼻喉科
- 可能疾病：神经性耳鸣、中耳炎、噪声损伤
- 紧急程度：绿色
- 就诊建议：描述耳鸣声音（嗡嗡/蝉鸣）

### 6. 耳痛/听力下降
- 推荐科室：耳鼻喉科
- 可能疾病：中耳炎、外耳道炎、突发性耳聋
- 紧急程度：黄色（突发听力下降→24h内就诊）
- 就诊建议：突发性耳聋黄金治疗期为72小时

### 7. 鼻塞/流涕
- 推荐科室：耳鼻喉科 / 呼吸内科
- 可能疾病：鼻炎、鼻窦炎、上呼吸道感染
- 紧急程度：绿色
- 就诊建议：描述分泌物性状（清/脓/血性）

### 8. 鼻出血
- 推荐科室：耳鼻喉科
- 可能疾病：鼻腔干燥、鼻外伤、高血压、血液病
- 紧急程度：黄色（大量出血不止→红色）
- 就诊建议：出血时前倾低头、捏鼻翼压迫止血

### 9. 咽痛/吞咽困难
- 推荐科室：耳鼻喉科 / 呼吸内科
- 可能疾病：咽炎、扁桃体炎、会厌炎
- 紧急程度：黄色（呼吸困难→红色，疑似急性会厌炎）
- 就诊建议：急性会厌炎可致窒息，需紧急处理

### 10. 声音嘶哑
- 推荐科室：耳鼻喉科
- 可能疾病：声带息肉、喉炎、甲状腺疾病
- 紧急程度：绿色（超过2周不愈→黄色）
- 就诊建议：长期声嘶需排除喉部肿瘤

### 11. 牙痛
- 推荐科室：口腔科
- 可能疾病：龋齿、牙髓炎、根尖周炎、智齿冠周炎
- 紧急程度：黄色（面部肿胀→红色）
- 就诊建议：描述疼痛性质（冷热刺激痛/自发痛/咬合痛）

### 12. 面部麻木/口角歪斜
- 推荐科室：神经内科
- 可能疾病：面神经炎（贝尔麻痹）、脑卒中
- 紧急程度：红色（可能是脑卒中，需立即急诊）
- 就诊建议：鉴别中枢性与周围性面瘫

### 13. 面部肿胀
- 推荐科室：口腔颌面外科 / 皮肤科
- 可能疾病：牙源性感染、腮腺炎、过敏反应
- 紧急程度：黄色（伴呼吸困难→红色）
- 就诊建议：说明肿胀发生速度

### 14. 颈部肿块
- 推荐科室：甲状腺外科 / 耳鼻喉科 / 普外科
- 可能疾病：淋巴结肿大、甲状腺结节、腮腺肿瘤
- 紧急程度：黄色
- 就诊建议：说明肿块大小、硬度、活动度

### 15. 颈部疼痛/活动受限
- 推荐科室：骨科 / 疼痛科
- 可能疾病：颈椎病、落枕、颈肌劳损
- 紧急程度：绿色（伴上肢麻木→黄色）
- 就诊建议：描述疼痛放射范围

## 二、胸部症状

### 16. 胸痛
- 推荐科室：急诊科 / 心内科
- 可能疾病：心绞痛、心肌梗死、肺栓塞、主动脉夹层、肋间神经痛
- 紧急程度：红色（剧烈胸痛/放射至左肩/伴出汗→立即急诊）
- 就诊建议：心源性胸痛可致命，宁可谨慎

### 17. 胸闷/憋气
- 推荐科室：心内科 / 呼吸内科
- 可能疾病：冠心病、心力衰竭、哮喘、肺气肿
- 紧急程度：黄色（静息状态下胸闷→红色）
- 就诊建议：描述诱发因素（活动/情绪/体位）

### 18. 心悸
- 推荐科室：心内科
- 可能疾病：心律失常、甲状腺功能亢进、贫血、焦虑
- 紧急程度：黄色（伴胸痛/晕厥→红色）
- 就诊建议：记录发作频率和持续时间

### 19. 咳嗽
- 推荐科室：呼吸内科
- 可能疾病：上呼吸道感染、支气管炎、肺炎、咳嗽变异性哮喘
- 紧急程度：绿色（伴咯血/呼吸困难→红色）
- 就诊建议：描述咳嗽性质（干咳/湿咳）

### 20. 咳痰
- 推荐科室：呼吸内科
- 可能疾病：支气管炎、肺炎、支气管扩张
- 紧急程度：绿色（大量脓痰/血痰→黄色）
- 就诊建议：描述痰液颜色和量

### 21. 咯血
- 推荐科室：呼吸内科 / 急诊科
- 可能疾病：肺结核、支气管扩张、肺癌、肺栓塞
- 紧急程度：红色
- 就诊建议：立即就医，保持患侧卧位

### 22. 气短/呼吸困难
- 推荐科室：呼吸内科 / 急诊科
- 可能疾病：哮喘急性发作、肺栓塞、心力衰竭、气胸
- 紧急程度：红色
- 就诊建议：立即就医或拨打120

### 23. 背部疼痛
- 推荐科室：骨科 / 心内科
- 可能疾病：肌肉劳损、脊柱疾病、心绞痛放射痛
- 紧急程度：黄色（撕裂样背痛→红色，疑似主动脉夹层）
- 就诊建议：描述疼痛位置和性质

## 三、腹部症状

### 24. 腹痛
- 推荐科室：消化内科 / 普外科 / 急诊科
- 可能疾病：胃肠炎、阑尾炎、胆囊炎、胰腺炎、肠梗阻
- 紧急程度：黄色（剧烈腹痛/板状腹/伴呕吐→红色）
- 就诊建议：描述疼痛位置（上腹/下腹/全腹）

### 25. 腹胀
- 推荐科室：消化内科
- 可能疾病：消化不良、肠道菌群失调、腹水
- 紧急程度：绿色（伴腹痛/呕吐→黄色）
- 就诊建议：说明饮食相关因素

### 26. 恶心/呕吐
- 推荐科室：消化内科 / 急诊科
- 可能疾病：胃肠炎、食物中毒、妊娠反应、颅内压增高
- 紧急程度：黄色（喷射性呕吐/伴头痛→红色）
- 就诊建议：说明呕吐物性状

### 27. 腹泻
- 推荐科室：消化内科 / 肠道门诊
- 可能疾病：急性胃肠炎、食物中毒、炎症性肠病
- 紧急程度：绿色（大量水样便/血便/伴脱水→黄色）
- 就诊建议：注意补充水分和电解质

### 28. 便秘
- 推荐科室：消化内科
- 可能疾病：功能性便秘、肠梗阻、甲状腺功能减退
- 紧急程度：绿色（伴腹痛/腹胀/呕吐→黄色）
- 就诊建议：说明排便习惯变化

### 29. 便血
- 推荐科室：消化内科 / 肛肠外科
- 可能疾病：痔疮、肛裂、炎症性肠病、结直肠肿瘤
- 紧急程度：黄色（大量便血→红色）
- 就诊建议：描述血液颜色（鲜红/暗红/柏油样）

### 30. 吞咽困难
- 推荐科室：消化内科 / 耳鼻喉科
- 可能疾病：食管狭窄、食管癌、贲门失弛缓症
- 紧急程度：黄色
- 就诊建议：说明固体/液体吞咽困难

### 31. 胃灼热/反酸
- 推荐科室：消化内科
- 可能疾病：胃食管反流病、胃炎、消化性溃疡
- 紧急程度：绿色
- 就诊建议：说明与饮食/体位的关系

### 32. 食欲下降
- 推荐科室：消化内科
- 可能疾病：消化系统疾病、甲状腺功能减退、抑郁症
- 紧急程度：绿色（伴消瘦→黄色）
- 就诊建议：记录体重变化

### 33. 右上腹痛
- 推荐科室：肝胆外科 / 消化内科
- 可能疾病：胆囊炎、胆结石、肝炎
- 紧急程度：黄色（剧烈绞痛→急诊）
- 就诊建议：说明与进食油腻食物的关系

### 34. 左下腹痛
- 推荐科室：消化内科 / 肛肠外科
- 可能疾病：结肠炎、憩室炎、肠道肿瘤
- 紧急程度：黄色
- 就诊建议：说明排便与疼痛的关系

## 四、四肢及骨骼症状

### 35. 关节疼痛
- 推荐科室：风湿免疫科 / 骨科
- 可能疾病：骨关节炎、类风湿关节炎、痛风
- 紧急程度：绿色（关节红肿热痛→黄色）
- 就诊建议：描述受累关节、对称性

### 36. 关节肿胀
- 推荐科室：风湿免疫科 / 骨科
- 可能疾病：关节积液、痛风急性发作、感染性关节炎
- 紧急程度：黄色（伴发热→红色）
- 就诊建议：说明肿胀发生速度

### 37. 腰背痛
- 推荐科室：骨科 / 疼痛科
- 可能疾病：腰椎间盘突出、腰肌劳损、强直性脊柱炎
- 紧急程度：绿色（伴下肢放射痛/大小便障碍→黄色）
- 就诊建议：描述疼痛与活动的关系

### 38. 肢体麻木
- 推荐科室：神经内科
- 可能疾病：颈椎病/腰椎病压迫神经、周围神经病变、脑卒中
- 紧急程度：黄色（突发单侧麻木→红色）
- 就诊建议：描述麻木范围

### 39. 肢体无力
- 推荐科室：神经内科
- 可能疾病：脑卒中、脊髓病变、重症肌无力
- 紧急程度：红色（突发偏侧无力→立即急诊）
- 就诊建议：可能是脑卒中，时间就是大脑

### 40. 肢体肿胀
- 推荐科室：血管外科 / 心内科
- 可能疾病：深静脉血栓、淋巴水肿、心力衰竭
- 紧急程度：黄色（单侧小腿肿胀→红色，疑似DVT）
- 就诊建议：单侧下肢肿胀需排除深静脉血栓

### 41. 肌肉疼痛
- 推荐科室：风湿免疫科 / 骨科
- 可能疾病：肌肉劳损、病毒感染、多发性肌炎
- 紧急程度：绿色（伴茶色尿→红色，疑似横纹肌溶解）
- 就诊建议：说明运动史和用药史

### 42. 骨折/外伤
- 推荐科室：骨科 / 急诊科
- 可能疾病：骨折、脱位、软组织损伤
- 紧急程度：黄色（开放性骨折/脊柱外伤→红色）
- 就诊建议：固定患处，勿随意搬动

### 43. 步态异常
- 推荐科室：神经内科 / 骨科
- 可能疾病：脑卒中后遗症、帕金森病、骨关节疾病
- 紧急程度：黄色
- 就诊建议：描述步态变化特征

## 五、皮肤症状

### 44. 皮疹
- 推荐科室：皮肤科
- 可能疾病：湿疹、荨麻疹、接触性皮炎、药疹
- 紧急程度：绿色（伴发热/黏膜受累→红色）
- 就诊建议：描述皮疹形态和分布

### 45. 皮肤瘙痒
- 推荐科室：皮肤科
- 可能疾病：皮肤干燥、过敏、肝胆疾病、肾功能不全
- 紧急程度：绿色
- 就诊建议：说明全身性或局部性

### 46. 皮肤溃疡
- 推荐科室：皮肤科 / 血管外科
- 可能疾病：下肢静脉性溃疡、糖尿病足、压疮
- 紧急程度：黄色（红肿热痛/脓性分泌物→红色）
- 就诊建议：说明创面持续时间

### 47. 皮肤黄染
- 推荐科室：消化内科 / 肝胆外科
- 可能疾病：黄疸（肝细胞性/梗阻性/溶血性）
- 紧急程度：黄色
- 就诊建议：检查肝功能和胆红素

### 48. 皮肤肿块
- 推荐科室：皮肤科 / 普外科
- 可能疾病：脂肪瘤、皮脂腺囊肿、皮肤肿瘤
- 紧急程度：绿色（快速增大→黄色）
- 就诊建议：说明肿块大小变化

### 49. 脱发
- 推荐科室：皮肤科
- 可能疾病：雄激素性脱发、斑秃、甲状腺疾病
- 紧急程度：绿色
- 就诊建议：描述脱发模式

### 50. 指甲异常
- 推荐科室：皮肤科
- 可能疾病：甲癣、银屑病甲、贫血
- 紧急程度：绿色
- 就诊建议：描述指甲变化特征

### 51. 水疱
- 推荐科室：皮肤科
- 可能疾病：带状疱疹、湿疹、烫伤
- 紧急程度：黄色（带状疱疹需72h内用药）
- 就诊建议：单侧带状分布水疱需排除带状疱疹

## 六、全身症状

### 52. 发热
- 推荐科室：发热门诊 / 呼吸内科 / 感染科
- 可能疾病：上呼吸道感染、肺炎、泌尿系感染、败血症
- 紧急程度：黄色（体温>39.5度/伴意识改变→红色）
- 就诊建议：记录体温曲线、热型

### 53. 高热
- 推荐科室：急诊科 / 发热门诊
- 可能疾病：重症感染、热射病
- 紧急程度：红色（体温>40度/伴抽搐→立即急诊）
- 就诊建议：物理降温，立即就医

### 54. 乏力/疲劳
- 推荐科室：全科 / 内分泌科
- 可能疾病：贫血、甲状腺功能减退、慢性疲劳综合征、抑郁症
- 紧急程度：绿色（伴消瘦/发热→黄色）
- 就诊建议：说明持续时间

### 55. 消瘦/体重下降
- 推荐科室：全科 / 肿瘤科 / 内分泌科
- 可能疾病：恶性肿瘤、糖尿病、甲状腺功能亢进
- 紧急程度：黄色（6个月内体重下降>5%需排查）
- 就诊建议：记录体重变化趋势

### 56. 水肿
- 推荐科室：肾内科 / 心内科
- 可能疾病：肾病综合征、心力衰竭、肝功能不全
- 紧急程度：黄色
- 就诊建议：描述水肿部位（下肢/眼睑/全身）

### 57. 盗汗
- 推荐科室：全科 / 呼吸内科
- 可能疾病：结核病、淋巴瘤、甲状腺功能亢进
- 紧急程度：黄色（伴消瘦/发热→需排查结核）
- 就诊建议：记录盗汗频率

### 58. 畏寒/寒战
- 推荐科室：发热门诊 / 感染科
- 可能疾病：感染性疾病、疟疾、败血症
- 紧急程度：黄色（伴高热→红色）
- 就诊建议：测量体温

### 59. 面色苍白
- 推荐科室：血液科 / 全科
- 可能疾病：贫血、失血、休克
- 紧急程度：黄色（伴心悸/气短→红色）
- 就诊建议：检查血常规

### 60. 淋巴结肿大
- 推荐科室：血液科 / 普外科
- 可能疾病：淋巴结炎、淋巴瘤、转移癌
- 紧急程度：黄色（无痛性进行性增大→需排查）
- 就诊建议：描述肿大部位、质地

## 七、泌尿生殖系统症状

### 61. 尿频/尿急/尿痛
- 推荐科室：泌尿外科 / 肾内科
- 可能疾病：尿路感染、前列腺炎、膀胱炎
- 紧急程度：绿色（伴发热/腰痛→黄色）
- 就诊建议：建议查尿常规

### 62. 血尿
- 推荐科室：泌尿外科 / 肾内科
- 可能疾病：泌尿系结石、肿瘤、肾炎
- 紧急程度：黄色（无痛性血尿→需排查肿瘤）
- 就诊建议：描述肉眼血尿或镜下血尿

### 63. 蛋白尿
- 推荐科室：肾内科
- 可能疾病：肾炎、肾病综合征
- 紧急程度：黄色
- 就诊建议：定期复查尿常规

### 64. 尿失禁
- 推荐科室：泌尿外科 / 妇科
- 可能疾病：压力性尿失禁、急迫性尿失禁、神经源性膀胱
- 紧急程度：绿色
- 就诊建议：描述尿失禁类型

### 65. 尿潴留
- 推荐科室：泌尿外科 / 急诊科
- 可能疾病：前列腺增生、尿道狭窄、神经源性膀胱
- 紧急程度：红色（需紧急导尿）
- 就诊建议：立即就医

### 66. 肾区疼痛
- 推荐科室：泌尿外科 / 急诊科
- 可能疾病：肾结石、肾盂肾炎
- 紧急程度：黄色（剧烈绞痛→急诊）
- 就诊建议：描述疼痛程度和放射方向

### 67. 男性阴囊肿块
- 推荐科室：泌尿外科
- 可能疾病：鞘膜积液、精索静脉曲张、睾丸肿瘤
- 紧急程度：黄色（突发剧痛→红色，疑似睾丸扭转）
- 就诊建议：睾丸扭转需6小时内手术

### 68. 月经异常
- 推荐科室：妇科
- 可能疾病：月经失调、子宫肌瘤、内分泌疾病
- 紧急程度：绿色（大量出血→黄色）
- 就诊建议：记录月经周期变化

### 69. 阴道异常出血
- 推荐科室：妇科
- 可能疾病：宫颈病变、子宫内膜病变、先兆流产
- 紧急程度：黄色（绝经后出血→需排查恶性肿瘤）
- 就诊建议：说明出血时间和量

### 70. 白带异常
- 推荐科室：妇科
- 可能疾病：阴道炎、宫颈炎、盆腔炎
- 紧急程度：绿色（伴腹痛/发热→黄色）
- 就诊建议：描述颜色、气味

### 71. 下腹痛（女性）
- 推荐科室：妇科
- 可能疾病：盆腔炎、卵巢囊肿、异位妊娠
- 紧急程度：黄色（剧烈腹痛/停经后出血→红色，疑似异位妊娠破裂）
- 就诊建议：育龄女性需排除妊娠

### 72. 不孕不育
- 推荐科室：生殖医学中心 / 妇科 / 泌尿外科
- 可能疾病：排卵障碍、输卵管阻塞、精液异常
- 紧急程度：绿色
- 就诊建议：夫妻双方同时就诊

## 八、精神心理及神经系统症状

### 73. 失眠
- 推荐科室：精神科 / 神经内科 / 心理咨询
- 可能疾病：焦虑症、抑郁症、睡眠呼吸暂停综合征
- 紧急程度：绿色
- 就诊建议：描述入睡困难/早醒/睡眠质量

### 74. 焦虑
- 推荐科室：精神科 / 心理咨询
- 可能疾病：焦虑症、甲状腺功能亢进
- 紧急程度：绿色
- 就诊建议：说明焦虑发作频率

### 75. 抑郁情绪
- 推荐科室：精神科 / 心理咨询
- 可能疾病：抑郁症、双相情感障碍
- 紧急程度：黄色（有自伤/自杀倾向→红色）
- 就诊建议：及时寻求专业帮助

### 76. 记忆力下降
- 推荐科室：神经内科 / 精神科
- 可能疾病：阿尔茨海默病、血管性痴呆、抑郁症
- 紧急程度：黄色
- 就诊建议：进行认知功能评估

### 77. 意识障碍
- 推荐科室：急诊科 / 神经内科
- 可能疾病：脑卒中、低血糖、癫痫、颅内感染
- 紧急程度：红色（立即急诊）
- 就诊建议：保持呼吸道通畅，立即拨打120

### 78. 抽搐/癫痫发作
- 推荐科室：神经内科 / 急诊科
- 可能疾病：癫痫、脑卒中、低血糖、颅内肿瘤
- 紧急程度：红色
- 就诊建议：保护患者防止外伤，记录发作表现

### 79. 言语障碍
- 推荐科室：神经内科 / 急诊科
- 可能疾病：脑卒中、阿尔茨海默病、失语症
- 紧急程度：红色（突发言语不清→疑似脑卒中）
- 就诊建议：时间就是大脑，立即急诊

### 80. 晕厥
- 推荐科室：心内科 / 神经内科 / 急诊科
- 可能疾病：血管迷走性晕厥、心律失常、脑供血不足
- 紧急程度：红色
- 就诊建议：立即就医排查心源性原因

## 九、其他常见症状

### 81. 口腔溃疡
- 推荐科室：口腔科
- 可能疾病：复发性阿弗他溃疡、白塞病、口腔癌
- 紧急程度：绿色（超过2周不愈→黄色）
- 就诊建议：长期不愈需活检排除恶变

### 82. 口干
- 推荐科室：口腔科 / 风湿免疫科
- 可能疾病：干燥综合征、药物副作用、糖尿病
- 紧急程度：绿色
- 就诊建议：检查自身免疫抗体

### 83. 味觉异常
- 推荐科室：耳鼻喉科 / 神经内科
- 可能疾病：锌缺乏、嗅觉神经损伤、脑部病变
- 紧急程度：绿色
- 就诊建议：描述味觉变化类型

### 84. 打鼾/睡眠呼吸暂停
- 推荐科室：呼吸内科 / 耳鼻喉科
- 可能疾病：阻塞性睡眠呼吸暂停综合征
- 紧急程度：绿色
- 就诊建议：建议做多导睡眠监测

### 85. 儿童发热
- 推荐科室：儿科 / 儿科急诊
- 可能疾病：上呼吸道感染、手足口病、肺炎
- 紧急程度：黄色（3个月以下婴儿发热/体温>39度→红色）
- 就诊建议：3个月以下婴儿发热需立即就医

### 86. 儿童咳嗽
- 推荐科室：儿科
- 可能疾病：上呼吸道感染、支气管炎、肺炎、异物吸入
- 紧急程度：绿色（伴呼吸困难/犬吠样咳嗽→黄色）
- 就诊建议：注意观察呼吸频率

### 87. 儿童腹泻
- 推荐科室：儿科
- 可能疾病：病毒性肠炎、细菌性肠炎
- 紧急程度：黄色（伴脱水→红色）
- 就诊建议：注意补充口服补液盐

### 88. 孕妇不适
- 推荐科室：产科
- 可能疾病：妊娠反应、妊娠并发症
- 紧急程度：黄色（阴道出血/腹痛/胎动减少→红色）
- 就诊建议：孕妇用药需遵医嘱

### 89. 老年人跌倒
- 推荐科室：急诊科 / 老年医学科
- 可能疾病：骨折、脑出血、晕厥
- 紧急程度：黄色（头部着地/意识改变→红色）
- 就诊建议：老年人跌倒需排查骨折和颅内出血

### 90. 术后不适
- 推荐科室：手术科室 / 外科
- 可能疾病：术后感染、伤口愈合不良
- 紧急程度：黄色（发热/伤口红肿→需检查）
- 就诊建议：说明手术类型和时间

## 十、症状交叉索引（按科室反查）

### 内科系统
- **心内科**：胸痛、胸闷、心悸、晕厥、水肿
- **呼吸内科**：咳嗽、咳痰、咯血、气短、打鼾
- **消化内科**：腹痛、腹胀、恶心呕吐、腹泻、便血、胃灼热
- **神经内科**：头痛、头晕、肢体麻木/无力、抽搐、言语障碍
- **内分泌科**：消瘦、乏力、甲状腺肿大、多饮多尿
- **肾内科**：血尿、蛋白尿、水肿、尿量异常
- **血液科**：贫血、出血倾向、淋巴结肿大
- **风湿免疫科**：关节疼痛/肿胀、肌肉疼痛、口干眼干
- **感染科/发热门诊**：发热、寒战、不明原因感染

### 外科系统
- **普外科**：急腹症、腹部肿块、乳腺肿块、疝
- **骨科**：骨折、关节脱位、腰背痛、颈椎病
- **泌尿外科**：泌尿系结石、前列腺疾病、阴囊肿块
- **神经外科**：颅内肿瘤、脑出血、脊髓病变
- **心胸外科**：心脏手术、肺部手术、食管手术
- **血管外科**：下肢静脉曲张、深静脉血栓、动脉硬化

### 专科系统
- **眼科**：视力问题、眼红眼痛、眼部异物感
- **耳鼻喉科**：耳痛耳鸣、鼻塞鼻出血、咽痛声嘶
- **口腔科**：牙痛、口腔溃疡、颌面部肿胀
- **皮肤科**：皮疹、瘙痒、皮肤溃疡、脱发
- **妇科**：月经异常、阴道出血、白带异常、下腹痛
- **儿科**：儿童发热、咳嗽、腹泻、发育异常
- **精神科**：失眠、焦虑、抑郁、认知障碍
- **肿瘤科**：不明原因消瘦、肿块、持续疼痛
- **老年医学科**：老年人多病共存、跌倒、用药管理
- **康复科**：脑卒中康复、术后康复、慢性疼痛
